## IV. Audio Works

| i. Audio - On Tangible Media (digital and analog) |
| :-- |
|  | **Preferred** | **Acceptable** |
| A. Sound recordings, in order of preference | 1. Final production/release version of content rather than pre-production version<br>2. Published (commercially manufactured) Compact Disc (CD audio) with all jackets, sleeves, inserts and intact enclosures<br>3. Original recorded (soundstage)/release channel format (e.g. stereo or mono).<br>4. Multi-channel Surround Sound/Immersive release in addition to stereo version if released in both, e.g., SACD ( [DSD](https://www.loc.gov/preservation/digital/formats/fdd/fdd000230.shtml)) and Blu-Ray Audio <br>5. Vinyl disc (LP) in addition to Compact Disc (CD) if released in both | 1. Published (“burned”) Archival CD-R (CD audio formats)<br>2. Archival quality recordable Compact Disc (CD-R) rather than vinyl disc <br>3. Vinyl disc rather than audio cassette<br>4. Audio cassette if only released as such |

i. Audio - On Tangible Medium (digital and analog)

![](https://www.loc.gov/images/arrow_up.gif)[Back to Top](https://www.loc.gov/preservation/resources/rfs/audio.html#skip_menu)

| ii. Audio - Media-independent (digital) |
| :-- |
|  | **Preferred** | **Acceptable** |
| A. Format, in order of preference | 1. Final production /release version of content rather than pre-production version<br>2. High Resolution Audio (HRA) files of final version produced (96kHz/24bit or higher [PCM](https://www.loc.gov/preservation/digital/formats/fdd/fdd000016.shtml), 2.8 MHz or higher [DSD](https://www.loc.gov/preservation/digital/formats/fdd/fdd000230.shtml)) in addition to Compact Disc (CD) when both are produced<br>3. WAVE file with embedded metadata ( [Broadcast WAVE](https://www.loc.gov/preservation/digital/formats/fdd/fdd000356.shtml)) rather than without embedded metadata (LC will specify fields)<br>4. File in native resolution rather than up-sampled resolution<br>5. Very high resolution file formats such as [DSD](https://www.loc.gov/preservation/digital/formats/fdd/fdd000230.shtml), [PCM](https://www.loc.gov/preservation/digital/formats/fdd/fdd000016.shtml) 176.4kHz, 192kHz up to 384kHz when produced for release in addition to Compact Disc (CD) when both are produced<br>6. Multi-channel Surround Sound/Immersive release in addition to stereo version delivered at highest resolution files available <br>7. Uncompressed files rather than compressed. | 1. CD Redbook quality files (44.1 kHz/16 bit) in [PCM](https://www.loc.gov/preservation/digital/formats/fdd/fdd000016.shtml) [WAVE](https://www.loc.gov/preservation/digital/formats/fdd/fdd000001.shtml) format or [DDP (Disc Description Protocol)](https://www.loc.gov/preservation/digital/formats/fdd/fdd000630.shtml)<br>2. Lossless compression scheme rather than lossy compression scheme<br>3. Highest resolution compressed version in a major standard compression scheme |
| **B. Accompanying Image/Text Files** **, in order of preference** | With final version of all accompanying image and text files; higher resolution images rather than lower<br>1. [TIFF](https://www.loc.gov/preservation/digital/formats/fdd/fdd000022.shtml) or [JPEG](https://www.loc.gov/preservation/digital/formats/fdd/fdd000017.shtml) formats for images<br>2. Text files in [PDF](https://www.loc.gov/preservation/digital/formats/fdd/fdd000030.shtml) |  |
| **C. Metadata** | 1. Provide most complete metadata set as delivered to online distributors (e.g. iTunes and Amazon), which may include elements not embedded in a file, including but not limited to:<br>   01. Song/work title<br>   02. Album title<br>   03. Artist<br>   04. Composer<br>   05. Genre<br>   06. Publisher/label name and issue number<br>   07. Location and date of performance<br>   08. Date of publication<br>   09. Standard identifier (e.g. ISRC, UPC) <br>   10. Any other entity identifiers<br>3. Provide data in a standard [XML](https://www.loc.gov/preservation/digital/formats/fdd/fdd000075.shtml)-based format, such as the Electronic Release Notification (ERN-DDEX) <br>4. If produced in a format that uses an [ADM (Audio Definition Model)](https://www.loc.gov/preservation/digital/formats/fdd/fdd000607.shtml), the ADM file accompanies<br>5. RSS feeds are desirable for podcasts |  |
| **D. Technological measures** | Files must contain no measures (such as digital rights management \[DRM\] technologies or encryption) that control access to or prevent use of the digital work.) |  |
